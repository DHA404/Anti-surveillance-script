## Known Issues | 已知问题

### Version 1.0.0
- Some websites may not function correctly when certain events are blocked | 当某些事件被阻止时，某些网站可能无法正常运行
- Virtual mouse may interfere with drag-and-drop functionality | 虚拟鼠标可能会干扰拖放功能
- Configuration import/export may fail on very large configurations | 配置导入/导出在非常大的配置上可能失败

### Workarounds | 解决方法
- Disable specific features for problematic websites | 对有问题的网站禁用特定功能
- Use site-specific configurations | 使用网站特定配置
- Clear configuration cache if issues occur | 如果出现问题，清除配置缓存
